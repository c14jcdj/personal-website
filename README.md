# chermainezimmerman.dev — personal portfolio

Portfolio site for Chermaine Zimmerman, Senior Frontend Engineer / Tech Lead.

Built with Next.js (App Router), TypeScript, and Tailwind CSS 4. All page content
lives in a single typed data file, `src/data/content.ts` — edit that file to update
copy, experience, or projects without touching components.

## Develop

```bash
npm install
npm run dev        # http://localhost:3000
npm run test:run   # Vitest + Testing Library
npm run build      # production build
```

## Deploy

Hosted on Vercel — every push to `main` deploys automatically.
